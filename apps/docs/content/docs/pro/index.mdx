Easy Forms Pro is a commercial add-on for teams that need repeating line items and
branching multi-step flows. Everything else — the engine, all 12 controls, validation,
dependencies, the linear wizard — is free and MIT licensed.

## What's free vs. what's Pro

| --- | --- | --- |

| Linear multi-step wizard | ✅ | ✅ |
| Plugins (autosave, logging) | ✅ | ✅ |

## How Pro is packaged

Pro follows the same split as the free library: **the npm package holds the behaviour, the
registry holds the markup.**

- **`@easy-forms/pro`** (npm) — hooks, control types, wizard routing, and the license layer.
  It ships **zero React components**.
- **`@ef-pro/*`** (authenticated shadcn registry) — the renderers you eject and own:
  `repeating-group` and `advanced-wizard`.

<Callout type="warn" title="The Pro renderers depend on the free registry">
	`@ef-pro/repeating-group` and `@ef-pro/advanced-wizard` declare registry dependencies on
	**`@easy-forms/group-renderer`** and **`@easy-forms/registry`** — items from the *free,
	public* `@easy-forms` registry. Configure both registries in `components.json` before
	installing, or the install will fail to resolve them. See [Installing Pro](/docs/pro/install).
</Callout>
